## 🔧 Customization Points

### Change Colors
Edit `app/globals.css`:
```css
--primary: #340002          /* Update these values */
--secondary: #b97d10
--tertiary: #e8c547
--quaternary: #6b0004
--quinary: #c98b1e
```

### Update Content
Edit `app/openmath/page.tsx`:
- Hero title
- Mission statement
- Program descriptions
- Research details
- Contact information

### Modify Layout
Edit CSS files:
- `app/globals.css` - Global styles
- `app/openmath/page.module.css` - Component styles
